# 建模规范（交付给 Twin Studio 的模型）

模型在编辑器「资源」中导入，在浏览器里实时渲染，最终可能在普通电脑和影院大屏上放映。下面的要求决定了画面效果、流畅度和设备能否绑定到具体部件。

## 1. 文件格式

- **glTF 2.0 二进制（.glb）**，一个文件包含全部贴图。不支持外部引用的贴图或 .bin（导入时会被拒绝），也暂不支持 FBX / OBJ。
- **网格压缩推荐 Meshopt，Draco 也支持。** 两种解码器都已打包进编辑器和 Viewer SDK，大屏现场离线也能打开；Meshopt 解码更快，优先使用。
- 贴图用 JPG / PNG / WebP（`EXT_texture_webp`），或 **KTX2**（`KHR_texture_basisu`）。KTX2 贴图在显卡里保持压缩，显存占用约为 PNG / WebP 的 1/4–1/6，大场景在普通电脑上更流畅。
- 推荐用 gltf-transform 一步完成压缩与贴图优化：

```bash
npx @gltf-transform/cli optimize input.glb output.glb --compress meshopt --texture-compress webp --texture-size 2048
```

贴图多、场景大时改用 KTX2（需要先安装 [KTX-Software](https://github.com/KhronosGroup/KTX-Software/releases)）：

```bash
npx @gltf-transform/cli optimize input.glb output.glb --compress meshopt --texture-compress ktx2 --texture-size 2048
```

## 2. 坐标与尺寸

- **1 个单位 = 1 米**，Y 轴向上（glTF 标准；Blender 导出时勾选 +Y Up）。按真实尺寸建模，不要缩放导出。
- **原点放在模型底部中心**。编辑器会把模型放到地面上，但原点合理时旋转、对齐和阵列更直观。
- 同类设备朝向一致（例如设备正面朝 +Z），方便批量摆放。
- 模型中不要包含灯光和相机：场景光照由编辑器的环境设置统一控制。

## 3. 层级与命名（影响设备绑定）

- **需要单独绑定、高亮、换材质或显隐的部件，做成独立节点**：每个储能柜、柜门、风机叶片、光伏组串、楼层等。编辑器里在模型上双击即可选中这些部件。纯装饰的静态部件尽量合并，以减少绘制次数。
- 节点名称有意义且稳定，例如 `ESS_Door_01`、`Turbine_Blade`。
- **给关键部件加自定义属性 `assetNodeId`**（Blender：物体属性 → 自定义属性；导出时勾选「包含 → 自定义属性」）。平台用它识别部件：重新导出模型、调整层级顺序后，已有的部件修改和绑定仍然有效。没有这个属性时，平台按层级位置识别部件，层级一变就会失效。

## 4. 面数与贴图预算

为了让普通电脑也能流畅放映：

| 项目 | 建议 |
| --- | --- |
| 单台设备 | 5k–30k 三角面 |
| 单栋建筑 | 20k–80k 三角面 |
| 整个园区场景 | 不超过 150 万三角面，总绘制批次 < 500 |
| 贴图尺寸 | 一般 1024，主体建筑最多 2048 |
| 材质 | 同类物体共用材质，不要每个零件一个材质 |
| 单个 .glb | 建议 < 20 MB（上限 128 MB） |

重复出现的设备（储能柜、光伏板、充电桩）只需交付一个模型，在编辑器里用「阵列复制」摆放。

## 5. 材质与夜景

- 使用 PBR 金属度 / 粗糙度工作流：基础色、金属度粗糙度、法线贴图；可以带烘焙 AO。
- **窗户、灯带、屏幕等夜间发光部位使用自发光（Emissive）**，可配合 `KHR_materials_emissive_strength` 提高亮度。编辑器的「科技夜景」氛围和泛光效果会让它们发光。
- 避免纯白和纯黑的基础色（建议亮度在 0.1–0.85 之间），这样白天和夜景的效果都更好。
- 透明材质只用在真正需要的地方（玻璃幕墙），透明物体多会影响性能。

## 6. 动画

- **模型自带的动画片段会自动播放**（默认第一个片段，循环）。在编辑器「属性 → 动画」里可以换片段、调速度、关闭循环或不播放。片段命名有意义，例如 `Door_Open`、`Conveyor_Run`。
- **持续旋转的部件（风机叶片、风扇、转轮）不需要做动画**：把它做成独立节点，**节点原点放在转轴中心**，编辑器里添加「部件运动」即可，转速还可以跟随实时数据（例如风机转速）。原点不在转轴上时，部件会绕错误的位置甩动。

## 7. 交付检查清单

- [ ] 单个 .glb，贴图内嵌，Meshopt（或 Draco）压缩
- [ ] 1 单位 = 1 米，Y 轴向上，原点在底部中心
- [ ] 需要绑定的部件是独立节点，名称有意义，并设置了 `assetNodeId`
- [ ] 需要旋转的部件原点在转轴中心
- [ ] 面数和贴图在预算内，材质已合并复用
- [ ] 夜间发光部位使用了自发光
- [ ] 在编辑器中导入后检查：比例正确、贴图正常、选中部件时轮廓完整
