# Twin Studio 编辑器

搭建零碳园区三维场景，绑定设备数据、配置告警与交互、编排导览，导出给数据大屏。

```bash
pnpm dev:editor      # 在仓库根目录运行
pnpm simulator       # 需要实时数据时另开一个终端
```

## 界面

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 文件 / 编辑 / 添加 / 视图菜单；编辑 ↔ 预览切换；撤销重做；保存状态；大屏预览；导出 |
| 左侧「场景」 | 对象层级：搜索、拖拽调整层级与顺序、显示 / 锁定、双击重命名、右键菜单；模型可展开查看其中的部件 |
| 左侧「资源」 | 内置模型、我的模型（导入 .glb）、基本体、绘制工具。拖入视口或单击放置 |
| 视口 | 左侧工具条（选择 / 移动 / 旋转 / 缩放、能流线 / 区域 / 标签 / 灯光、测量、吸附、坐标系）；右上视图切换；右键快捷菜单（粘贴到这里、替换模型、绑定、在此添加…） |
| 右侧检查器 | 选中对象（或模型中的部件）：属性 / 数据 / 特效 / 交互；未选中：环境 / 数据 / 放映。左右面板和底部面板可拖动调整大小 |
| 底部 | 视角书签与导览时间轴 |

## 常用流程

1. **搭场景**：拖入模型和基本体；用「能流线」「区域」画出能量流向和功能分区；多选后「组合」形成分区（分组在大屏中可作为图层开关）。
2. **氛围**：未选中对象时在「环境」页选择预设（白天 / 黄昏 / 科技夜景 / 展台），或调整时间、天空、光照、泛光、雾、天气。
3. **绑数据**：选中对象 →「数据」→ 选设备类型 → 绑定；多选可批量绑定（编号自动递增）。在「场景 → 数据」填写 WebSocket 地址。
   - **绑到部件**：再次单击已选中的模型（或直接双击）进入模型，选中其中的部件（柜门、叶片、楼层…），数据 / 特效 / 交互页签随即作用于该部件。部件还可以单独改材质（玻璃、金属、发光、透视等预设）、隐藏、移动或删除；Esc 回到整个模型。
   - **模型动画**：模型自带的动画自动播放；「属性 → 动画」可添加部件运动，例如风机叶片按实时转速旋转。
   - **模型更新**：建模同事交付新版本后，「属性 → 模型 → 替换」选择新文件，可只换当前对象或场景中全部同款，位置、部件修改、绑定和特效都保留。
4. **告警与特效**：「特效」页添加常驻特效（围栏、光柱、数据标牌…）或告警规则（如温度 > 60 显示严重告警）。
5. **交互**：「交互」页配置单击 / 双击 / 悬停时的动作，「通知大屏」会向大屏发送事件。
6. **导览**：底部保存视角，新建导览并为每一步填写字幕、飞行和停留时间；在「放映」页设置空闲自动播放。
7. **预览**：顶栏「预览」按大屏效果运行交互、规则和导览；「大屏预览」用 Viewer SDK 打开导出后的项目包。
8. **导出**：「导出」生成 `.twin.zip` 交给数据大屏。

所有修改自动保存在本机浏览器（另有 Ctrl/⌘ + S）。「文件 → 历史版本」保留每次手动保存和每 10 分钟的自动版本（每个项目最近 30 个），可命名、预览缩略图并一键恢复（恢复也能撤销）。项目和资源也可通过项目包备份与迁移。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Q / W / E / R | 选择 / 移动 / 旋转 / 缩放 |
| F | 聚焦选中对象（双击对象：选中最内层并聚焦；在模型上双击选中部件） |
| 再次单击已选模型，Esc | 进入模型选择部件（逐级深入），回到上一级 |
| Alt + 单击 | 直接选中组内对象 |
| Shift / Ctrl / ⌘ + 单击 | 多选 |
| Shift + 拖动 | 框选（加 Ctrl / ⌘ 追加） |
| Ctrl/⌘ + Z，Ctrl/⌘ + Shift + Z | 撤销 / 重做 |
| Ctrl/⌘ + D / C / V | 创建副本 / 复制 / 粘贴 |
| Ctrl/⌘ + G，Ctrl/⌘ + Shift + G | 组合 / 取消组合 |
| Delete，H，End | 删除，显示 / 隐藏，放到地面 |
| 0 / 7 / 1 / 3 | 透视 / 顶 / 前 / 右视图 |
| M | 测量距离 / 面积（单击取点，可点在模型表面；回车结束，Esc 退出） |
| 右键单击 | 快捷菜单（右键拖动仍是平移镜头） |
| P，Esc | 进入 / 退出预览 |
| 绘制时 Enter / Backspace / Esc | 完成 / 撤销最后一个点 / 取消 |

## 代码结构

- `src/studio/EditorSession.ts`：一个打开的项目。持有文档仓库、引擎、场景同步、选择、手柄、绘制、数据、特效、规则、导览和预览；所有编辑都是文档事务。
- `src/components/studio/`：编辑器界面，只读文档、调用 session 方法，从不直接修改三维对象。
- `src/components/ui/`：数值拖拽框、滑块、颜色、开关等基础控件。
- 文档编辑操作（组合、改层级、复制、删除级联…）在 `packages/core/src/document/sceneOps.ts`，有单元测试。
- 浏览器测试：`tests/studio.mjs`（编辑器）、`tests/zero-carbon-demo.mjs`（示例），通过 `pnpm test:e2e` 运行。
