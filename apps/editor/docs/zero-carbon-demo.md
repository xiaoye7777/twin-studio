# 零碳智慧园区示例

在项目页点击「零碳园区示例」生成一份全新的独立副本并直接打开，不会覆盖已有项目。

## 内容

- **分区（分组）**：储能区、光伏区、风电区、建筑、能流、道路与绿化。分组可在大屏中当作图层开关。
- **设备**：8 台储能柜（ESS-001…008）、3 台风机（WT-001…003）、光伏区（PV-001）、综合能源站电表（EM-001）、绿色办公楼（BLD-001）。
- **告警**：每台储能柜两条规则（温度 > 60 高温预警，告警为真时严重告警）。模拟器让 ESS-003 周期性过热，用于演示告警。
- **能流线**：光伏 / 风电 → 能源站 → 储能、办公楼、制造与仓储；园区边界光墙；能源站雷达与数据标牌。
- **视角与导览**：园区全景、光伏与风电、储能区、综合能源站、办公与制造 5 个视角；「零碳园区导览」带字幕，空闲 45 秒后自动循环播放。
- **交互**：储能柜单击选中并通知大屏（`open-device-detail`），双击聚焦，悬停高亮。

## 演示顺序

1. 运行 `pnpm simulator`，在编辑器「场景 → 数据」确认 WebSocket 已连接，数据标牌开始跳动。
2. 切到「预览」，单击储能柜、双击聚焦；在底部导览面板播放「零碳园区导览」。
3. 「环境」页切换「科技夜景」，观察能流线与告警特效在夜间的效果。
4. 「大屏预览」或导出项目包给数据大屏，演示大屏与场景双向联动。

## 模型资源

模型为 Kenney 的 CC0 低多边形资源（`public/demo-assets/`，许可见 `CREDITS.md`），只用于可行性演示。正式项目由建模同事替换：导入新的 GLB，替换实例后重新绑定设备即可，设备 ID、变量、规则和交互可以沿用。建模要求见 `docs/modeling-guide.md`。
