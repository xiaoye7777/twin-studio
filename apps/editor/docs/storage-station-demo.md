# 储能电站案例

在「三维场景」页点「生成案例 → 储能电站（精细模型）」。每次生成一份新项目，不影响已有项目。生成逻辑在 `src/demo/storageStation.ts`，模型是真实比例（米），由 `scripts/` 下的脚本建模。

## 里面有什么

| 区域 | 内容 |
| --- | --- |
| 储能区 | 21 台储能柜（轻量模型）分三排，电缆桥架接入 3 台箱变 |
| 样机展示 | 1 台完整模型单独放在控制区旁的台面上，四周留出爆炸的空间 |
| 升压区 | 2 台主变、2 个高压出线间隔，导线接到站外铁塔 |
| 控制区 | 站控室、35kV 开关舱 |
| 光储充 | 光伏车棚、4 台充电桩 |
| 周界 | 围栏、道闸、高杆灯、消防栓、标识牌 |

## 怎么看

- **单击储能柜**开关柜门，**双击**爆炸和复位。样机是完整爆炸，能看到每个电池包和电芯；成排的柜子只向前、向上展开，不穿到隔壁，电池包是一整块。
- 左栏「视角」里有 7 个视角和 1 条导览。
- 环境面板可以一键换黄昏、科技夜景。

## 数据

全部读数都是写死的示例值，放在三个静态接口里，接口名带「示例静态数据」：储能系统、升压与配电、站控与光储充。13 号柜的温度故意写成 47.6 ℃，用来展示高温预警。接真实设备时，在「场景 → 数据 → 数据源」里停用它们，再添加真实接口。
