# 数据大屏编辑器

导航栏「数据大屏」：用拖拽方式搭建可视化大屏，读取三维场景中设备的实时数据，并与三维场景双向联动。纯前端实现，大屏保存在本机浏览器（IndexedDB），可导出 / 导入 JSON。

## 快速开始

1. 先在「三维场景」中创建项目（例如零碳园区示例），配置好设备绑定和 WebSocket 数据源并保存。
2. 「数据大屏 → 新建大屏」选择「园区运营监控」模板、画布尺寸和关联的三维场景，创建后即得到一块完整的大屏：能源指标、储能图表、实时趋势、中央三维场景、视角 / 图层 / 导览控件、告警列表、设备详情和储能运行表格，全部绑定场景的实时数据。
3. 在编辑器中拖入、调整组件；顶栏「预览」在新标签页打开草稿，编辑器每次保存后预览自动刷新。
4. 满意后点「发布」，把放映链接（`/screens/<id>/play`）在大屏、电视或拼接屏上打开。之后的修改只是草稿，再次发布才会出现在放映中。

## 编辑器

| 区域 | 内容 |
| --- | --- |
| 左侧「组件」 | 按类别列出全部组件，拖到画布或单击添加 |
| 左侧「图层」 | 前后顺序（可拖动调整）、重命名、锁定、隐藏；组合显示为可折叠的分组 |
| 画布 | 按设计尺寸绘制；Ctrl/⌘ + 滚轮缩放，滚轮 / 空格拖动 / 中键平移；拖动移动（吸附页面、其他组件的边与中线和参考线，按住 Alt 关闭）；八个手柄调整大小（Shift 保持比例），多选或组合时整体等比缩放；拖框多选；右键菜单 |
| 标尺与参考线 | 上方和左侧标尺（显示选中组件的范围）；从标尺拖出参考线，拖动调整，拖回标尺删除，左上角清除全部；⇧R 显示 / 隐藏 |
| 组合 | 选中多个组件 ⌘G 组合、⇧⌘G 取消；点击组合中任一组件选中整组，双击单独选中它；复制组合保持组合 |
| 右侧检查器 | 选中组件：样式（含入场动画）/ 数据 / 交互；多选：对齐与分布；未选中：页面设置（主题、画布尺寸、屏幕适配、背景、入场动画、大屏变量、关联三维场景） |
| 顶栏 | 撤销 / 重做、缩放、吸附、标尺、快捷键说明（?）、历史版本、预览草稿、发布 |

快捷键（按 ? 查看完整列表）：Ctrl/⌘ + Z / Shift+Z（撤销 / 重做）、C / V / D（复制 / 粘贴 / 副本，可粘贴到另一块大屏）、A（全选）、G / Shift+G（组合 / 取消组合）、0（适应窗口）、+ / -（缩放）；方向键微调 1 px（Shift 10 px）；Delete 删除；[ / ] 下移 / 上移一层；⇧R 标尺。

## 组件

| 类别 | 组件 |
| --- | --- |
| 三维 | 三维场景（关联项目经 Viewer SDK 加载，点击设备即在大屏中选中） |
| 图表 | 折线图、柱状图（含横向）、柱线混合、饼图 / 环形图 / 玫瑰图、仪表盘、雷达图、散点图（可用气泡大小）、漏斗图（ECharts） |
| 指标 | 指标卡、进度条、环形进度、数字翻牌器 |
| 文字 | 标题、文本（`{value}` 显示数据）、时间、跑马灯 |
| 列表 | 滚动表格、排行榜（TOP N 比例条）、告警列表、设备详情 |
| 筛选 | 下拉筛选、标签切换（选项来自静态数据、接口或设备）、日期选择（日 / 月）——都设置大屏变量 |
| 控件 | 视角切换、导览控制、图层开关、按钮（点击执行任意交互动作） |
| 媒体 / 装饰 | 图片、视频（mp4 / webm）、网页、边框、标题栏、分割线 |

每个组件的样式面板由组件定义的字段自动生成；新增组件只需在 `src/screen/widgets/` 中写一个 Vue 组件并注册定义（字段、默认值、数据形态）。某个组件显示出错时只在它自己的位置显示提示，不影响整块大屏。

## 数据

| 来源 | 说明 |
| --- | --- |
| 静态数据 | 手写 JSON：一个数值，或对象数组（第一个文字列为分类，数字列为数据） |
| 接口数据 | 业务后端的 HTTP 接口：按中文名选择接口、填参数、选字段，详见 [数据接口](data-api.md) |
| 单个设备变量 | 某台设备一个变量的实时值 |
| 多设备汇总 | 按设备类型或指定设备，对一个变量求合计 / 平均 / 最大 / 最小 / 计数 |
| 设备列表 | 每台设备一行，选择的变量为列（柱状图、表格） |
| 实时趋势 | 最近一段时间的实时值（打开大屏后每 2 秒记录一次） |
| 当前告警 | 场景告警规则当前触发的告警 |
| 选中设备 | 三维中点击或其他组件选中的设备的全部变量 |
| 场景统计 | 设备数、有实时数据的设备数、告警数 |

实时值只来自关联场景配置的 WebSocket 数据源，与三维编辑器、Viewer 一致；未连接时不显示数值。

接口由技术人员在导航栏「数据接口」中登记一次（可从 Swagger / OpenAPI 文档导入、同步接口清单或粘贴 cURL），业务人员在组件中直接选用，不需要看接口文档。

## 大屏变量与联动

页面设置（点击画布空白处）→「大屏变量」添加变量，如「园区」「月份」。接口参数可以跟随变量；点击动作「设置大屏变量」把变量设为点击的那一行 / 那根柱子 / 固定值，跟随它的组件随即重新请求。内置变量：选中设备编号 / 名称、今天、本月——例如设备历史曲线的「设备编号」跟随「选中设备编号」，在三维中点哪台设备就显示哪台的历史。

筛选控件（下拉、标签、日期）直接设置变量，不需要配置点击动作：例如「近 7 天 / 近 14 天 / 近 30 天」标签设置变量「天数」，能源趋势图的「天数」参数跟随它。

## 主题与入场动画

- **主题**：页面设置顶部的科技蓝、能源绿、暗金、赛博紫、政务红，一键统一修改背景和所有组件的颜色（一步撤销）；指标卡等按调色板位置换色，保持彼此区分。
- **入场动画**：组件「样式 → 入场动画」选择淡入、上下左右滑入或放大浮现，设置延迟和时长，▶ 在编辑器中预览；页面设置「一键依次入场」按从上到下、从左到右的顺序编排全部组件（园区模板默认带有）。动画只在放映 / 预览打开时播放；浏览器暂停动画时组件也会按时显示。

## 发布与历史版本

- **草稿与发布**：编辑器自动保存的是草稿；「预览」显示草稿并随保存刷新。「发布」把当前内容定为放映版本，放映链接 `/screens/<id>/play` 只显示已发布的版本，并在每次发布后自动刷新。大屏列表和顶栏标出「未发布 / 有修改未发布 / 已发布」。
- **历史版本**：顶栏时钟图标。发布的版本、手动保存的版本一直保留；每次编辑后离开编辑器自动保存一个版本（保留最近 20 个），每个版本带缩略图，可预览或恢复（恢复前自动保存当前内容，恢复后也可撤销）。

## 三维联动

- 三维 → 大屏：在三维场景组件中点击设备，设为「选中设备」，设备详情等组件随之更新。
- 大屏 → 三维：表格行、告警、图表、指标卡、图片的点击动作可以选中并定位设备（固定设备或点击的那一行 / 那根柱子）、飞到视角、回到全景、播放 / 停止导览、开关图层或打开网址；视角切换、导览控制、图层开关控件自带对应操作。

## 放映适配

页面设置中的「屏幕适配」决定设计画布如何铺到实际屏幕：等比完整显示、等比铺满（裁边）、宽度铺满、高度铺满、拉伸铺满。预览页按此缩放，图表按最终尺寸清晰渲染，右上角可全屏。
